# Generación Privilegiada (GP) — Sitio Oficial de Streaming

Sitio web oficial del medio y programa de streaming cristiano para una nueva generación: **GENERACIÓN PRIVILEGIADA (GP)**.

## 🚀 Tecnologías

- **Vite** + **React 18** + **TypeScript**
- **Tailwind CSS** con sistema de diseño a medida (paleta `#070A0F`, acentos dorados `#C9A45C`, negro profundo)
- **Akira Expanded** (Tipografía de identidad oficial) + **Plus Jakarta Sans**
- **Lucide Icons**
- Optimizado para despliegue continuo en **Vercel**
